Cadastro de alunos

Um exemplo completo dos documentos: variáveis, funções, decisões, DOM, máscara de CPF e armazenamento trabalhando juntos.

Use apenas dados fictícios. A lista fica no localStorage deste navegador. O formulário vira um rascunho no sessionStorage desta aba. A máscara formata o CPF e confere a quantidade de dígitos, sem validar um documento real.

03

Lista salva neste navegador

0 aluno(s)

Nenhum aluno cadastrado. Faça seu primeiro teste acima.

    Recarregue a página: a lista é recuperada com getItem() e JSON.parse(). Excluir um item atualiza o array, salva o novo JSON e reconstrói a lista.

    Leia o fluxo no código

    1. submit chama a função do evento; preventDefault() evita recarregar a página.
    2. O código lê os campos, converte e valida as notas.
    3. calcularMedia() retorna um número; verificarSituacao() retorna uma string.
    4. Um objeto reúne os dados; push() o adiciona ao array.
    5. JSON.stringify() transforma a lista em texto para salvar.
    6. textContent, classList e createElement() mostram os resultados.
