01

Variáveis e tipos de dados

Referência: páginas 65 a 69

Uma variável é um nome que usamos para guardar um valor.

ENTENDA

O que estamos guardando?

let permite reatribuir um valor. const impede reatribuir a variável. Você também pode encontrar var em códigos antigos; aqui usaremos let e const.

  • "Ana" → string: texto.
  • 18 e 7.5 → number: números.
  • true / false → boolean: verdadeiro ou falso.
  • undefined → variável sem valor atribuído.
  • null → ausência de valor definida de propósito.
  • ["JS", "HTML"] → array: uma lista.
  • { nome: "Ana" } → object: dados agrupados.

Arrays são objetos. Uma const pode guardar um array ou objeto cujo conteúdo muda; ela impede a troca da referência.

EXPERIMENTE

Conheça seus dados

Os valores e seus tipos vão aparecer aqui.

O valor de um input chega como texto. Usamos Number() para convertê-lo em número.

Veja a ideia no código
const nome = "Ana";       // string
let idade = 18;          // number
idade = idade + 1;       // let pode receber outro valor
const maiorDeIdade = idade >= 18; // boolean
let apelido;             // undefined
const resposta = null;   // ausência intencional
const materias = ["JS", "HTML"]; // array
const aluno = { nome: "Ana", idade: 18 }; // objeto

console.log(typeof nome); // "string"
console.log(typeof idade); // "number"
// Curiosidade histórica: typeof null retorna "object".

02

Lógica condicional

Referência: páginas 70 a 72

O programa pode tomar decisões de acordo com uma condição.

ENTENDA

Se isso, faça aquilo

if significa “se”. else if testa outra condição. else executa quando nenhuma das anteriores é verdadeira.

  • >= maior ou igual · < menor.
  • === compara valor e tipo · !== verifica se são diferentes.
  • && significa “e” · || significa “ou”.
  • ! inverte um boolean.

Atenção: = atribui um valor; === compara. Neste exemplo, as regras de nota são apenas para praticar.

EXPERIMENTE

Como foi a nota?

7 a 10: aprovação. De 5 até menos de 7: recuperação. Abaixo de 5: reprovação.

Digite uma nota para testar as condições.

Veja a ideia no código
// A nota já deve ter sido validada entre 0 e 10.
if (nota >= 7) {
  resultado.textContent = "Aprovação!";
} else if (nota >= 5) {
  resultado.textContent = "Recuperação.";
} else {
  resultado.textContent = "Reprovação.";
}

Seu desafio: teste as notas 4.9, 5, 6.9 e 7. Descubra exatamente quando o resultado muda.

03

Funções

Referência: páginas 73 a 85

Uma função reúne instruções e só executa quando é chamada.

ENTENDA

Uma tarefa, um nome

Usamos function para declarar uma função. Os parâmetros são os nomes que recebem dados. Os argumentos são os valores passados na chamada.

Em somar(2, 3), os argumentos são 2 e 3. O return devolve o resultado e encerra a função.

A função somar calcula. A função mostrarSoma lê os campos e mostra o resultado na página.

EXPERIMENTE

Uma função que soma

O retorno da função vai aparecer aqui.

Preencha os dois campos. O número zero também é um valor válido.

Veja a ideia no código
function somar(a, b) {
  return a + b;
}

const total = somar(2, 3);
console.log(total); // 5

// No evento, passamos o nome da função, sem ().
// Assim ela só executa quando o botão recebe o clique.
botaoSoma.addEventListener("click", mostrarSoma);

04

Manipulação de DOM

Referência: páginas 73 a 85

O DOM representa os elementos do HTML como objetos que o JavaScript pode acessar.

ENTENDA

O HTML pode mudar

  • getElementById() encontra um elemento pelo ID.
  • textContent lê ou altera o texto.
  • classList.toggle() adiciona ou retira uma classe CSS.
  • createElement() cria um elemento.
  • appendChild() coloca o elemento na página.
  • remove() retira o elemento da página.

addEventListener() liga um evento, como um clique, a uma função. Usamos textContent para tratar o que você digita como texto.

EXPERIMENTE

Mude a página

Eu sou um texto do HTML. Você pode me mudar!

Veja a ideia no código

const item = document.createElement("li");
item.textContent = "Praticar funções";

05

Máscara de entrada

Referência: páginas 73 a 85

Uma máscara organiza os caracteres de um campo para facilitar a leitura.

ENTENDA

De números a um formato

Vamos formatar um celular brasileiro com DDD e 11 dígitos, sem o código do país. O evento input roda quando o conteúdo do campo muda, inclusive ao colar.

replace(/\D/g, "") remove tudo que não é dígito. Aqui, \D significa “não dígito” e g aplica a troca em todas as ocorrências.

slice(inicio, fim) pega uma parte do texto, sem incluir a posição final. As posições começam em zero.

Máscara é formatação: ela não verifica se o número de celular existe. Este exemplo formata ao final do campo; edições no meio podem mover o cursor.

EXPERIMENTE

Digite ou cole um celular

Use 11 dígitos, sem +55. Letras serão removidas e dígitos excedentes serão ignorados.

0 de 11 dígitos preenchidos.

Veja a ideia no código
let numeros = campoCelular.value.replace(/\D/g, "");
numeros = numeros.slice(0, 11); // no máximo 11 dígitos

// Exemplo com todos os dígitos preenchidos:
const formatado = "(" + numeros.slice(0, 2) + ") "
  + numeros.slice(2, 7) + "-" + numeros.slice(7, 11);

// No script.js, if e else tratam também os números incompletos.

06

localStorage e sessionStorage

Armazenamento no navegador

Guarde pequenos valores no navegador usando uma chave e um valor.

Qual é a diferença?
RecursoDuração
localStorageContinua após recarregar e fechar o navegador, até ser removido ou ter os dados do site apagados.
sessionStorageContinua ao recarregar a mesma aba. Em geral, termina ao fechar a aba; a restauração de sessão do navegador pode recuperar os dados.

setItem() salva, getItem() lê e removeItem() remove uma chave. Os valores são guardados como texto. Quando a chave não existe, a leitura retorna null.

FICA PARA DEPOIS

localStorage

Nenhum nome salvo.

NESTA ABA

sessionStorage

Nenhuma meta salva nesta aba.

Use dados de teste. O armazenamento pertence à origem do site (protocolo, domínio e porta). O modo privado, permissões ou a abertura direta por arquivo podem limitar seu funcionamento.

Veja a ideia no código
// A chave identifica o valor salvo.
localStorage.setItem("revisaofront_nome", "Ana");
const nomeSalvo = localStorage.getItem("revisaofront_nome");
localStorage.removeItem("revisaofront_nome");

sessionStorage.setItem("revisaofront_meta", "Estudar JS");
const metaSalva = sessionStorage.getItem("revisaofront_meta");
sessionStorage.removeItem("revisaofront_meta");

// No script.js usamos try/catch para mostrar um aviso
// caso o navegador bloqueie o armazenamento.
